# Авторство персон и маппинг SillyTavern-карточек

## Принцип: протокол, не биография

Карточка-характеристика («ты мудр, стар и любим народом») даёт картонного
персонажа. Карточка-протокол («один вопрос за сообщение; изгнанника не трогать
без разрешения защитника») даёт работающую стойку. Дисциплина > легенда.

## Секции карточки

- **Frontmatter**: `name` (русское имя), `type` (therapy | analytics |
  interlocutor), `stance` (школа/подход), `voice` (тон).
- **Контракт**: Решает / Не подходит — почему эту стойку звать вместо другой.
  Если «Решает» нельзя сформулировать одной строкой — карточка не готова.
- **Дисциплина**: 2–4 измеримых правила. «Будь эмпатичным» — не измеримо;
  «ноль советов, даже запрошенных» — измеримо.
- **Первый ход**: реплика входа. Проверяй, что она работает вне идеального
  контекста (пользователь может позвать персону с середины мысли).
- **Голос**: 2–3 реплики. Это few-shot якорь: mirroring по тону, длине,
  ритму важнее любых прилагательных.
- **Табу**: 1–3 никогда.

## Импорт из SillyTavern (V2/V3)

Карточка ST — PNG с JSON в tEXt-чанке (ключ `chara`, base64; V3 — `ccv3`,
предпочтителен) или голый JSON (`spec: chara_card_v2`). Маппинг в нашу
карточку:

| ST | сюда |
|---|---|
| `data.name` | `name` |
| `data.description` + `data.personality` | проза в «Контракт.Решает» / контекст — сократить вдвое |
| `data.system_prompt` | черновик «Дисциплины» — переформулировать в измеримые правила |
| `data.first_mes` | «Первый ход» (адаптировать под чат, сцены — сжать) |
| `data.mes_example` | «Голос» (выбрать 2–3 лучших) |
| `data.character_book` | обычно выбросить; постоянные записи — одной строкой в Контракт |

Парсеры: npm `character-card-utils`, `@lenml/char-card-reader`; спеки:
malfoyslastname/character-card-spec-v2, kwaroran/character-card-spec-v3.
Типичный ST-«психолог» — два абзаца биографии и ноль правил: после маппинга
дисциплину дописывать руками.
